# API Testing Projects

This folder contains manual API testing projects created using Postman and JSONPlaceholder REST API.

## Projects

### CRUD Testing

Scope:

* GET requests
* POST requests
* PUT requests
* DELETE requests

Artifacts:

* Test Cases
* Postman Collection

### Advanced Testing

Scope:

* Positive testing
* Negative testing
* Response validation
* Status code validation

Artifacts:

* Test Cases
* Postman Collection

## Tools Used

* Postman
* REST API
* JSONPlaceholder
* HTTP/HTTPS
